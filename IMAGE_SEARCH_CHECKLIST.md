# Activity Images - Unsplash Search Checklist

This document lists all activities that need images. Search for each on [Unsplash](https://unsplash.com) and fill in the image URLs.

## How to Find Images on Unsplash

1. Go to https://unsplash.com
2. Search for the activity name (or related keywords)
3. Click on the image you want
4. Copy the URL (format: `https://unsplash.com/photos/PHOTO_ID`)
5. Paste the URL in the "Image URL" column below

All Unsplash images are free to use under the [Unsplash License](https://unsplash.com/license) - no attribution required (though appreciated).

## Tips for Better Search Results

1. **Use specific keywords**: "Space Needle Seattle" vs just "Space Needle"
2. **Try variations**: "Pike Place Market" vs "Seattle public market"
3. **Use location tags**: Many Unsplash photos are location-tagged
4. **Check photographer collections**: Browse collections from photographers who specialize in these cities
5. **Generic alternatives**: For specific businesses, search for generic images (e.g., "ice cream shop" instead of "Molly Moon's")
